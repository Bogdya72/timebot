# Тихая ферма — Telegram Mini App

Полноценное WebApp‑приложение внутри Telegram:
- покупка семян
- рост культур
- сбор и продажа
- рынок с динамическими ценами
- порча на складе
- погода + болезни
- набеги и саботаж

## Локальный запуск

```
/Users/bogdanbogdanov/Desktop/TimeBot/run.sh
```

Открой бота и нажми кнопку **Открыть ферму**.

## Переменные окружения

- `BOT_TOKEN`
- `WEBAPP_URL` — публичный адрес WebApp (локально: `http://localhost:8080`)
- `DEBUG_ALLOW=1` — разрешает локальный запуск без Telegram (через `?uid=...`)

## Локальная отладка

Можно открыть браузер:

```
http://localhost:8080/?uid=123
```

Это позволяет тестировать интерфейс без Telegram. В продакшене отключай `DEBUG_ALLOW`.
